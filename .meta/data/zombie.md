# 僵尸数据参考

> 引用来源: https://plantsvszombies.fandom.com/wiki

## 攻击机制说明

**僵尸啃食速率（原版游戏实测数据）**:
- **正常速度**: 4HP/4cs（每4厘秒造成4点伤害）= **100HP/秒**
- **减速状态**: 4HP/8cs（每8厘秒造成4点伤害）= **50HP/秒**

> **注**: 原版游戏使用 **0.01秒 = 1厘秒 (cs)** 作为时间单位  
> 表格中的"攻击力"数值（如270、640）可能是游戏设计概念，实际游戏中僵尸攻击速率固定

## 详细说明

### 普通僵尸 (Zombie)
- **生命值**: 270
- **攻击速率**: 
  - 正常: 4HP/4cs (100HP/秒)
  - 减速: 4HP/8cs (50HP/秒)
- **移动速度**: 正常
- **生成点数**: 1
- **首次出现**: 关卡1-1
- **外观变化**: 生命值少于180时断臂，少于90时断头
- **特殊能力**: 无

### 路障僵尸 (Conehead Zombie)
- **生命值**: 640 (路障370 + 本体270)
- **攻击速率**: 
  - 正常: 4HP/4cs (100HP/秒)
  - 减速: 4HP/8cs (50HP/秒)
- **移动速度**: 正常
- **生成点数**: 2
- **首次出现**: 关卡1-3
- **外观变化**: 
  - 路障：370点生命值，少于226、113时改变外观，0时掉落
  - 本体：270点生命值，少于180时断臂，少于90时断头
- **特殊能力**: 路障提供额外防护

### 撑杆僵尸 (Pole Vaulting Zombie)
- **生命值**: 500
- **攻击速率**: 
  - 正常: 4HP/4cs (100HP/秒)
  - 减速: 4HP/8cs (50HP/秒)
- **移动速度**: 快速 → 正常（跳跃后）
- **生成点数**: 2
- **首次出现**: 关卡1-6
- **外观变化**: 生命值少于333时断臂，少于166时断头
- **特殊能力**: 
  - 快速向前冲刺，撑杆跳过接触到的第一株植物
  - 会忽略荆棘草、荆棘石以及内部有植物的南瓜
  - 跳跃后失去杆子，变为正常速度
  - 起跳后1.09~1.24秒进行判定，忽略内部有植物的南瓜
  - 如果范围内编号最低的植物是高坚果，会被拦截
- **弱点**:
  - 高坚果（无法跳过）
  - 分裂豌豆、杨桃、忧郁菇（从背后攻击）
  - 窝瓜（当他试图跳过时直接消灭）

### 铁桶僵尸 (Buckethead Zombie)
- **生命值**: 1370 (铁桶1100 + 本体270)
- **攻击速率**: 
  - 正常: 4HP/4cs (100HP/秒)
  - 减速: 4HP/8cs (50HP/秒)
- **移动速度**: 正常
- **生成点数**: 4
- **首次出现**: 关卡1-8
- **外观变化**: 
  - 铁桶：1100点生命值，少于733、366时改变外观，0时掉落
  - 本体：270点生命值，少于180时断臂，少于90时断头
- **特殊能力**: 
  - 铁桶比路障更坚固，提供强力防护
  - 可在泳池路出现，会变成铁桶鸭子救生圈僵尸
- **弱点**: 
  - 磁铁蘑菇可移除铁桶，使其变为普通僵尸强度
