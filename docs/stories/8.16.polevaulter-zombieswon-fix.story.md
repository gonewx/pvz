# Story 8.16: 撑杆僵尸胜利动画特殊处理

## Status
Approved

## Story
**As a** 玩家,
**I want** 在撑杆僵尸触发失败条件时看到合理的进入房子动画,
**so that** 我能体验到视觉上连贯、符合逻辑的僵尸获胜流程，而不是看到撑杆僵尸以持杆或跳跃姿态进入房子的不协调画面。

## Background

**触发问题**：Story 8.8（僵尸获胜流程）和 Story 8.9（撑杆僵尸）各自实现完整，但组合使用时出现视觉问题。

**问题描述**：
- 撑杆僵尸的造型与普通僵尸差异较大（持杆跑步、跳跃姿态）
- 在僵尸获胜流程 Phase 2 中，撑杆僵尸可能显示不合常理的视觉状态
- 进入房子的场景需要僵尸以行走姿态表现

**解决方案**：
在 Phase 2 开始时检测触发僵尸类型，对撑杆僵尸执行特殊处理：
1. 直接传送到第2个目标位置（跳过移动阶段）
2. 强制切换为行走动画（无杆状态）
3. 与摄像机左移同步，从目标位置向左走入房子

## Acceptance Criteria

### AC 1: 撑杆僵尸类型检测
1. Phase 2 开始时检测触发失败的僵尸是否为撑杆僵尸类型
2. 通过 `BehaviorComponent.UnitID == types.UnitIDZombiePolevaulter` 判断
3. 非撑杆僵尸保持原有 Phase 2 逻辑不变

### AC 2: 位置传送
1. 撑杆僵尸直接传送到第2个目标位置（`target2X`, `target1Y`）
2. 跳过从当前位置移动到目标位置的阶段
3. 位置传送与摄像机左移同时发生（Phase 2 开始瞬间）

### AC 3: 动画强制切换
1. 强制切换为 `walk` 动画组合（无杆行走状态）
2. 使用 `AnimationCommandComponent` 触发动画切换
3. 确保 `PoleVaultComponent.HasPole = false`（已丢弃撑杆）
4. 确保 `PoleVaultComponent.IsJumping = false`（非跳跃状态）

### AC 4: 流程同步
1. 传送和动画切换后，僵尸继续向左移动进入房子
2. 标记 `ZombieReachedTarget1 = true` 和 `ZombieStartedWalking = true`
3. 后续流程与普通僵尸的 Phase 2 后半段一致
4. Phase 3 进入条件不变（摄像机到位 且 僵尸到达第2目标位置）

### AC 5: 测试覆盖
1. 添加单元测试验证撑杆僵尸特殊处理逻辑
2. 测试撑杆僵尸触发失败时的位置传送
3. 测试动画切换和撑杆状态重置
4. 确保普通僵尸的行为不受影响

### 关键代码片段

```go
// 在 Phase 2 初始化逻辑中添加（phaseComp.PhaseTimer == deltaTime 分支内）

// 检测是否为撑杆僵尸，需要特殊处理
behaviorComp, hasBehaviorComp := ecs.GetComponent[*components.BehaviorComponent](s.entityManager, phaseComp.TriggerZombieID)
if hasBehaviorComp && behaviorComp.UnitID == types.UnitIDZombiePolevaulter {
    // 撑杆僵尸特殊处理
    log.Printf("[ZombiesWonPhaseSystem] 检测到撑杆僵尸，执行特殊处理")

    // 1. 计算目标位置
    target1X := config.GameOverDoorMaskX + Phase2ZombieTarget1OffsetX
    target1Y := config.GameOverDoorMaskY + Phase2ZombieTarget1OffsetY
    target2X := target1X + Phase2ZombieTarget2OffsetX

    // 2. 传送到第2个目标位置
    if posComp, ok := ecs.GetComponent[*components.PositionComponent](s.entityManager, phaseComp.TriggerZombieID); ok {
        posComp.X = target2X
        posComp.Y = target1Y
        log.Printf("[ZombiesWonPhaseSystem] 撑杆僵尸传送到 (%.2f, %.2f)", posComp.X, posComp.Y)
    }

    // 3. 强制切换为行走动画（无杆状态）
    ecs.AddComponent(s.entityManager, phaseComp.TriggerZombieID, &components.AnimationCommandComponent{
        UnitID:    types.UnitIDZombiePolevaulter,
        ComboName: "walk",
        Processed: false,
    })

    // 4. 确保撑杆状态已重置
    if poleVault, ok := ecs.GetComponent[*components.PoleVaultComponent](s.entityManager, phaseComp.TriggerZombieID); ok {
        poleVault.HasPole = false
        poleVault.IsJumping = false
    }

    // 5. 标记已到达目标，触发继续向左走入房子
    phaseComp.ZombieReachedTarget1 = true
    phaseComp.ZombieStartedWalking = true
}
```

### 依赖组件
- `BehaviorComponent` - 僵尸类型信息（UnitID 字段）
- `PoleVaultComponent` - 撑杆状态
- `PositionComponent` - 位置信息
- `AnimationCommandComponent` - 动画切换命令
