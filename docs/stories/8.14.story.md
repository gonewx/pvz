#### convertToBlack 方法复用

如果来信内容需要将白色文字转换为黑色（类似 HelpPanelModule 中 ZombieNoteHelp.png 的处理），可复用 `convertToBlack` 方法的逻辑：

```go
// convertToBlack 将透明底白字转换为透明底黑字（使用预乘 Alpha）
//
// 处理流程：
//   1. 读取源图像素
//   2. 将所有像素的 RGB 设置为黑色 (0, 0, 0)
//   3. 保持 Alpha 通道不变
//
// 为什么使用预乘 Alpha：
//   - 半透明边缘（如 R=200, A=200）在非预乘模式下会显示为浅灰色
//   - 预乘后边缘更暗，消除白边
//
// 参数：
//   - src: 原图（透明底白字，非预乘 Alpha）
//
// 返回：
//   - 处理后的图片（透明底黑字，预乘 Alpha）
func (m *ZombieNotePanelModule) convertToBlack(src *ebiten.Image) *ebiten.Image {
    bounds := src.Bounds()
    width := bounds.Dx()
    height := bounds.Dy()

    result := ebiten.NewImage(width, height)
    pixels := make([]byte, width*height*4)
    src.ReadPixels(pixels)

    for i := 0; i < len(pixels); i += 4 {
        alpha := pixels[i+3]
        pixels[i+0] = 0     // R = 0
        pixels[i+1] = 0     // G = 0
        pixels[i+2] = 0     // B = 0
        pixels[i+3] = alpha // A 保持不变
    }

    result.WritePixels(pixels)
    return result
}
```

**注意**：ZombieNote1.png 可能已经是黑色文字透明背景，需要先检查原图格式：
- 如果是黑底白字 → 需要 `ApplyAlphaMask` + `convertToBlack`
- 如果已是透明底黑字 → 直接使用，无需转换

#### 阶段流程（来信奖励专属）

```
appearing → waiting → expanding → fadingOut → fadingIn → showing → closing
                                    ↑            ↑
                                    └────────────┴─── 来信奖励专属阶段
```

#### fadingOut 阶段实现

```go
func (ras *RewardAnimationSystem) updateFadingOutPhase(dt float64, rewardComp *components.RewardAnimationComponent) {
    progress := rewardComp.ElapsedTime / RewardNoteFadeOutDuration
    if progress >= 1.0 {
        progress = 1.0
        // 淡出完成，进入淡入阶段
        rewardComp.Phase = "fadingIn"
        rewardComp.ElapsedTime = 0
        // 清理卡包实体
        ras.cleanupRewardEntity()
        // 创建来信面板
        ras.createNotePanelModule()
    }
    // FadeAlpha 用于 Draw 方法绘制黑色遮罩
    rewardComp.FadeAlpha = float32(progress)
}
```

#### fadingIn 阶段实现

```go
func (ras *RewardAnimationSystem) updateFadingInPhase(dt float64, rewardComp *components.RewardAnimationComponent) {
    progress := rewardComp.ElapsedTime / RewardNoteFadeInDuration
    if progress >= 1.0 {
        progress = 1.0
        // 淡入完成，进入显示阶段
        rewardComp.Phase = "showing"
        rewardComp.ElapsedTime = 0
    }
    // 面板 alpha 从 0 渐变到 1
    rewardComp.PanelAlpha = float32(progress)
}
```
