# Story 8.13: 奖励动画系统行为优化与主菜单按钮

## Status

Done

---

## Story

**As a** 玩家,
**I want** 奖励动画中卡包弹出后只有点击卡包才进入下一阶段，并且默认在奖励面板上显示主菜单按钮,
**so that** 我能更精准地操作界面，并且能方便地返回主菜单。

---

## Acceptance Criteria

### 1. 卡包等待阶段交互优化

1. **AC1**: waiting 阶段中，只有点击卡包本身或按空格键才进入 expanding 阶段
2. **AC2**: waiting 阶段中，界面其他元素（如收集阳光、查看UI等）保持可操作状态
3. **AC3**: 鼠标悬停在卡包上时切换为手形光标
4. **AC4**: 点击卡包时播放点击音效并进入展开阶段

### 2. 主菜单按钮功能

5. **AC5**: 关卡配置支持 `showMainMenuButton` 字段，默认为 true（1-1、1-2 设置为 false）
6. **AC6**: 奖励面板右上角正确显示主菜单按钮（使用 `IMAGE_SEEDCHOOSER_BUTTON2`）
7. **AC7**: 鼠标悬停主菜单按钮时切换为手形光标，显示发光效果（`IMAGE_SEEDCHOOSER_BUTTON2_GLOW`），按钮文字为无阴影的黑色
8. **AC8**: 点击主菜单按钮后跳转到主菜单界面

### 3. 配置与组件

9. **AC9**: `LevelConfig` 新增 `ShowMainMenuButton` 字段，默认为 true
10. **AC10**: `RewardPanelComponent` 新增 `ShowMainMenuButton` 字段
11. **AC11**: 配置常量中定义主菜单按钮位置（右上角）

### 4. 测试覆盖

12. **AC12**: 单元测试覆盖率 ≥ 80%，覆盖卡包点击检测和按钮悬浮检测逻辑

### 关键实现细节

#### 1. 卡包点击检测逻辑

```go
// isCardPackClicked 检查鼠标点击是否在卡包范围内
func (ras *RewardAnimationSystem) isCardPackClicked(mouseX, mouseY float64) bool {
    if ras.rewardEntity == 0 {
        return false
    }

    posComp, ok := ecs.GetComponent[*components.PositionComponent](ras.entityManager, ras.rewardEntity)
    if !ok {
        return false
    }

    // 获取卡片尺寸（考虑缩放）
    var cardWidth, cardHeight float64
    if cardComp, ok := ecs.GetComponent[*components.PlantCardComponent](ras.entityManager, ras.rewardEntity); ok && cardComp.BackgroundImage != nil {
        cardWidth = float64(cardComp.BackgroundImage.Bounds().Dx()) * cardComp.CardScale
        cardHeight = float64(cardComp.BackgroundImage.Bounds().Dy()) * cardComp.CardScale
    } else {
        // 工具奖励默认尺寸
        cardWidth = 100.0 * config.PlantCardScale
        cardHeight = 140.0 * config.PlantCardScale
    }

    // AABB 碰撞检测
    return mouseX >= posComp.X && mouseX <= posComp.X+cardWidth &&
           mouseY >= posComp.Y && mouseY <= posComp.Y+cardHeight
}
```

#### 2. waiting 阶段修改

**当前代码** (`reward_animation_phases.go:96-124`):
```go
func (ras *RewardAnimationSystem) updateWaitingPhase(dt float64, rewardComp *components.RewardAnimationComponent) {
    justPressed, _, _ := utils.IsPointerJustPressed()
    clicked := justPressed || inpututil.IsKeyJustPressed(ebiten.KeySpace)

    if clicked {
        // 进入 expanding 阶段
    }
}
```

**修改为**:
```go
func (ras *RewardAnimationSystem) updateWaitingPhase(dt float64, rewardComp *components.RewardAnimationComponent) {
    justPressed, mouseX, mouseY := utils.IsPointerJustPressed()
    spacePressed := inpututil.IsKeyJustPressed(ebiten.KeySpace)

    // 只有点击卡包本身或按空格键才进入下一阶段
    cardClicked := justPressed && ras.isCardPackClicked(float64(mouseX), float64(mouseY))

    if cardClicked || spacePressed {
        // 进入 expanding 阶段
    }
}
```

- **零耦合**: 不直接调用其他系统，通过组件和 EntityManager 通信
