# Story 8.9: Level 1-6 实现 - 寒冰射手与撑杆僵尸

## Status
Ready

## Story
**As a** 玩家,
**I want** 能够游玩第一章关卡 1-6，体验寒冰射手的减速效果和撑杆僵尸的跳跃机制,
**so that** 我可以学习"控制"类植物的使用策略，并掌握应对特殊能力僵尸的战术。

## Acceptance Criteria

### 1. 关卡 1-6 配置与实现
- 场地布局：完整 5 行草地（行 1-5）
- 波次配置：**1 面旗帜**（10 波，Final Wave 在第 10 波）
- 解锁植物：寒冰射手（Snow Pea）
- 新增僵尸：撑杆僵尸（Pole Vaulting Zombie）
- 初始阳光：50（标准关卡配置）
- 可用植物：豌豆射手、向日葵、樱桃炸弹、坚果墙、土豆雷
- 核心教学：引入"控制"类植物（减速）和应对"特殊能力"僵尸（跳跃）的策略
- 开场动画：标准开场（镜头右移预告僵尸 → 返回草坪）
- 关卡完成后显示奖励动画和寒冰射手介绍面板

### 2. 寒冰射手实现
- 外观：冰蓝色豌豆射手，头部有冰晶装饰
- 攻击方式：发射冰豌豆（蓝色/浅蓝色子弹）
- 伤害值：与普通豌豆相同（20 伤害/次）
- 减速效果：命中僵尸后降低其移动速度 50%
- 减速持续时间：10 秒（每次命中刷新计时器）
- 减速视觉效果：被减速的僵尸显示冰蓝色叠加层或动画减慢效果
- 攻击间隔：与豌豆射手相同（约 1.4 秒）
- 阳光消耗：175（比豌豆射手贵 75）
- 冷却时间：快速（约 7.5 秒）
- Reanim 动画：使用 `data/reanim_config/snowpea.yaml` 配置

### 3. 冰豌豆投射物实现
- 外观：冰蓝色豌豆子弹，带有寒气拖尾效果（可选粒子效果）
- 移动速度：与普通豌豆相同
- 命中效果：播放冰碎裂动画/粒子效果
- 命中音效：冰碎裂音效
- 减速标记：命中僵尸时添加 `SlowedComponent` 组件

### 4. 撑杆僵尸实现
- 外观：手持撑杆的运动型僵尸
- 生命值：500（高于普通僵尸 270）
- **初始移动速度**：高速（约 8.5 像素/秒，普通僵尸的 1.8 倍）
- **跳跃后移动速度**：普通速度（约 4.7 像素/秒，与普通僵尸相同）
- 攻击力：与普通僵尸相同（100 伤害/次）

### 5. 撑杆僵尸跳跃机制
- **跳跃触发条件**：遇到第一个植物时触发跳跃
- **跳跃行为**：
  - 播放撑杆跳跃动画
  - 跳过遇到的第一个植物（不造成伤害）
  - 撑杆丢弃（视觉上撑杆消失或掉落）
  - 跳跃后速度降为普通速度
- **跳跃后状态**：
  - 不再具备跳跃能力
  - 变为普通行走状态
  - 遇到下一个植物时正常攻击
- **跳跃距离**：约 1.5 格（足以跳过单个植物）
- **战术设计**：
  - 玩家可用坚果墙"消耗"其跳跃能力
  - 第一列不放植物可让其提前跳跃
  - 寒冰射手的减速效果可有效克制其高速

### 6. 减速系统实现
- 创建 `SlowedComponent` 组件：
  ```go
  type SlowedComponent struct {
      SpeedMultiplier float64 // 速度倍率（0.5 表示减速 50%）
      Duration        float64 // 剩余持续时间（秒）
      VisualEffect    bool    // 是否显示视觉效果
  }
  ```
- 创建 `SlowEffectSystem` 系统：
  - 处理减速效果的应用和持续时间
  - 与 `VelocityComponent` 交互修改移动速度
  - 减速效果结束时恢复原速
  - 支持减速效果叠加刷新（重置计时器）

### 7. 土豆地雷完整实现（AC 补充）
根据 chapter1.md 要求，需要完善土豆地雷功能：
- **准备阶段**：种植后需要 15 秒准备时间（`anim_idle` 动画，埋在地下只显示泥土）
- **准备中状态**：埋在地下，易受攻击
- **准备就绪**：播放 `anim_rise` 动画，从地下升起
- **待机状态**：播放 `anim_armed` 动画（武装就绪，显示土豆雷本体）
- **触发条件**：僵尸接触到土豆地雷时触发爆炸
- **爆炸范围**：1x1 格（单格）
- **爆炸伤害**：1800 点（足以秒杀大多数普通僵尸）
- **爆炸动画**：`anim_mashed` + 爆炸粒子效果
- **成就**：用土豆地雷击杀僵尸获得"土豆炸弹！"成就（预留）

**动画说明**（根据 PotatoMine.reanim 帧定义）：
| 动画名 | 可见帧范围 | 含义 |
|--------|-----------|------|
| `anim_idle` | 帧 0 | 埋在地下（只显示泥土） |
| `anim_rise` | 帧 1-19 | 升起动画 |
| `anim_armed` | 帧 20-34 | 武装就绪（显示土豆雷本体） |

### Architecture Context
[Source: docs/architecture/data-models.md]

**现有相关组件**：
- `VelocityComponent`：存储实体速度向量
- `BehaviorComponent`：定义实体行为类型

**需要新增的组件**：

### ECS 架构原则
[Source: docs/architecture/coding-standards.md]

- **零耦合原则**：系统之间通过组件通信，不直接调用
- **数据-行为分离**：Component 只存储数据，System 处理逻辑
- **使用 AnimationCommandComponent**：触发动画时添加组件而非直接调用
