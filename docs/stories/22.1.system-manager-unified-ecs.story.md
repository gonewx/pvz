# Story 22.1: SystemManager 统一 ECS 系统管理

## Status
Ready for Review

## Story
**As a** 开发者,
**I want** 一个统一的 SystemManager 来管理所有 ECS 系统的创建和更新,
**so that** 新增系统时只需在一处添加，避免 GameScene 和 verify_gameplay 之间的代码重复和遗漏。

## Acceptance Criteria

### 1. SystemManager 核心功能
- 创建 `pkg/game/system_manager.go` 文件
- SystemManager 结构体包含所有 ECS 系统的引用
- 提供 `NewSystemManager()` 工厂函数创建并初始化所有系统
- 提供 `Update(deltaTime float64)` 方法按正确顺序更新所有系统
- 提供各系统的访问器方法（Getter）

### 2. SystemOptions 配置结构
- 定义 `SystemOptions` 结构体控制哪些系统需要创建
- 支持启用/禁用可选系统（如 Tutorial、ConveyorBelt、Reward 等）
- 支持传入外部依赖（如 ResourceManager、GameState、LawnGridEntityID 等）

### 3. 系统创建顺序
- 按依赖关系正确排序系统创建顺序
- 确保有依赖的系统在其依赖系统之后创建
- 示例顺序：
  1. ReanimSystem（无依赖）
  2. RenderSystem（依赖 ReanimSystem）
  3. LawnGridSystem（无依赖）
  4. BehaviorSystem（依赖 LawnGridSystem）
  5. PhysicsSystem（无依赖）
  6. PoleVaultSystem（无依赖）
  7. SlowEffectSystem（无依赖）
  8. ...其他系统

### 4. 系统更新顺序
- `Update()` 方法按正确的逻辑顺序调用各系统
- 关键顺序约束：
  - PoleVaultSystem 必须在 BehaviorSystem 之前
  - SlowEffectSystem 在 PhysicsSystem 之后
  - ReanimSystem 在 BehaviorSystem 之前（处理动画命令）
  - LifetimeSystem 在最后（清理过期实体）

### 5. GameScene 重构
- 修改 `pkg/scenes/game_scene.go` 使用 SystemManager
- 移除分散的系统字段，改用 `systemManager *game.SystemManager`
- 通过访问器方法获取需要直接访问的系统
- 保持现有功能不变

### 6. verify_gameplay 重构
- 修改 `cmd/verify_gameplay/main.go` 使用 SystemManager
- 移除重复的系统初始化代码
- 确保所有系统都自动包含，不会遗漏

### 7. 向后兼容
- 重构后所有现有功能正常工作
- 所有现有测试通过
- 游戏可正常运行关卡 1-1 到 1-6

```
ReanimSystem
    └── RenderSystem (需要 SetReanimSystem)
    └── InputSystem (需要 reanimSystem 参数)
    └── RewardSystem (需要 reanimSystem 参数)

LawnGridSystem
    └── BehaviorSystem (需要 lawnGridSystem 参数)
    └── PlantPreviewSystem (需要 lawnGridSystem)
    └── InputSystem (需要 lawnGridSystem)
    └── TutorialSystem (需要 lawnGridSystem)

WaveSpawnSystem
    └── LevelSystem (需要 waveSpawnSystem)
    └── TutorialSystem (需要访问 WaveTimingSystem)

LawnmowerSystem
    └── LevelSystem (需要 lawnmowerSystem)

ParticleSystem
    └── RewardSystem (需要 particleSystem)

RewardSystem
    └── ZombiesWonPhaseSystem (需要 rewardSystem 用于触发奖励)
```

### ECS 架构原则
[Source: CLAUDE.md]
- **组件 (Components)**: 仅存储数据，不包含任何方法
- **系统 (Systems)**: 仅包含逻辑，通过查询组件处理实体
- **系统隔离**: 系统之间严禁直接调用，必须通过 EntityManager 或 EventBus 通信
