# Story 8.12: 关卡 1-8 实现 - 选卡系统与大嘴花行为

## Status

Approved

---

## Story

**As a** 玩家,
**I want** 体验关卡 1-8，使用选卡界面选择植物（包括大嘴花），并应对新出现的铁桶僵尸,
**so that** 我能学习策略性选择植物阵容，并体验"重甲单位"带来的火力检测挑战

---

## Acceptance Criteria

### 1. 选卡系统（游戏循环变更）

1. **AC1**: 关卡 1-8 进入时触发选卡流程（镜头预览 → 选卡界面 → 开始游戏）
2. **AC2**: 选卡界面显示顶部卡槽（6格）和植物仓库（7张已解锁植物）
3. **AC3**: 点击仓库卡片可选入卡槽，点击卡槽卡片可取消选择
4. **AC4**: 选满6张后"一起摇滚吧!"按钮激活可点击
5. **AC5**: 鼠标悬停植物卡片显示名称和描述提示
6. **AC6**: 右侧僵尸预览区显示本关僵尸阵容，悬停显示僵尸名称提示

### 2. 双发射手实现

7. **AC7**: 双发射手能正确显示在选卡界面，阳光消耗 200
8. **AC8**: 双发射手每次攻击发射 2 颗豌豆
9. **AC9**: 关卡完成后解锁双发射手，显示奖励动画和介绍面板

### 3. 铁桶僵尸实现

10. **AC10**: 铁桶僵尸正确显示（头戴铁桶）
11. **AC11**: 铁桶僵尸生命值正确（铁桶1100 + 本体270 = 1370）
12. **AC12**: 铁桶被打掉后变为普通僵尸外观

### 4. 大嘴花行为（归属本 Story）

13. **AC13**: 大嘴花显示在可选植物列表中（7种之一）
14. **AC14**: 大嘴花检测到前方2格内僵尸时执行吞噬攻击（1800伤害）
15. **AC15**: 吞噬后进入42秒消化期，播放咀嚼动画
16. **AC16**: 对无法吞噬目标（巨人僵尸等）使用撕咬攻击（40伤害）

### 5. 关卡配置

17. **AC17**: 关卡 1-8 配置正确：5行草地、1面旗帜、10波僵尸
18. **AC18**: 僵尸池包含：普通、路障、撑杆、铁桶僵尸

#### 仓库界面实现细节

**1. 顶部卡槽区域 (Seed Slots)**
- 位置：屏幕左上角，阳光计数器右侧
- 显示：6个卡槽，与游戏中植物选择栏**位置和样式相同**
- 空卡槽：使用 `SeedPacketSilhouette.png` 显示轮廓剪影
- 已选卡片：显示植物卡片 + 底部阳光消耗数字
- 交互：点击已选卡片可取消选择

**2. 选卡面板 (Seed Chooser Panel)**
- 位置：屏幕左侧，棕色背景面板
- 标题："选择你的植物"（面板顶部居中）
- 背景：`SeedChooser_Background.png`（棕色网格纹理）

**3. 植物仓库 (Inventory)**
- 位置：选卡面板内，标题下方
- 显示：所有已解锁植物卡片（7张），水平排列
- 每张卡片显示：
  - 植物图标
  - 底部阳光消耗数字（50/100/150/175/25等）
- 排列顺序：按解锁顺序
  - Peashooter(100) → Sunflower(50) → Cherry Bomb(150) → Wall-nut(50) → Potato Mine(25) → Snow Pea(175) → Chomper(150)
- 卡片状态：
  - **可选**: 正常显示，鼠标悬停时高亮边框
  - **已选**: 卡片变灰（grayscale），不可再次点击
  - **卡槽已满时剩余卡片**: 不变灰，但不可点击

**4. 开始按钮**
- 位置：选卡面板底部居中
- 文本："一起摇滚吧!"
- 状态：
  | 状态 | 图片 | 条件 |
  |------|------|------|
  | 禁用 | `SeedChooser_Button_Disabled.png` | 未选满6张 |
  | 激活 | `SeedChooser_Button.png` + `SeedChooser_Button_Glow.png` | 选满6张 |
  | 悬停 | 按钮发光增强 | 鼠标悬停且已激活 |

**5. 僵尸预览区 (Zombie Preview)**
- 位置：屏幕右侧，显示草坪和僵尸
- 显示：本关会出现的僵尸阵容（站在草坪右侧道路上）
- 僵尸类型示例：普通僵尸、路障僵尸、铁桶僵尸、旗帜僵尸
- 悬停提示：鼠标悬停显示僵尸名称
- 右上角："菜单" 按钮

**6. 卡片选择动画**
- 选择：卡片从仓库位置**飞入**顶部卡槽的第一个空位
  - 动画：抛物线轨迹，约 0.3 秒
  - 音效：`seedlift.ogg`
- 取消：卡片从卡槽**飞回**仓库原位置
  - 动画：抛物线轨迹，约 0.3 秒
  - 音效：`seedlift.ogg`（选择/取消共用同一音效）

**7. 悬停提示 (Tooltip)**
- 触发：鼠标悬停在植物卡片上
- 样式：与游戏中植物选择栏的提示相同
- 内容：
  - 第一行：植物名称（加粗）
  - 第二行：植物描述（详细功能说明）

#### 交互逻辑
1. **选择植物**: 点击仓库卡片 → 卡片飞入顶部卡槽 → 仓库卡片变灰
   - 音效: `seedlift.ogg`
2. **取消选择**: 点击卡槽卡片 → 卡片飞回仓库 → 仓库卡片恢复高亮
   - 音效: `seedlift.ogg`
3. **卡槽已满**: 选满6张时，第7张卡片无法点击，开始按钮激活
4. **鼠标悬停**: 显示植物名称（第一行）和详细描述（第二行）

#### 僵尸预览
- 右侧显示僵尸阵容，鼠标悬停显示僵尸名称提示
- 帮助玩家决定是否携带"寒冰射手"或"大嘴花"

## QA Results

### 2025-12-17 QA 修复

**发现的问题：**

1. **卡片飞行动画问题**：卡片点击后立即显示在卡槽，应该等飞行动画完成后才显示
2. **仓库禁用状态缺失**：已选中的卡片在仓库中没有显示禁用状态
3. **按钮文字位置**：按钮文字没有垂直居中
4. **按钮文字颜色**：禁用时应为黑色，可点击时应为金黄色（与标题一致）
5. **手形光标缺失**：悬停在卡片和按钮上时没有切换为手形光标
6. **Glow 效果问题**：按钮悬停时 Glow 效果没有显示

**修复方案：**

1. **卡片飞行动画**：
   - 在 `SeedChooserInputSystem` 添加 `pendingSlotPlants` 列表追踪正在飞行的卡片
   - 卡片点击后先添加到 pending 列表，飞行动画完成后才添加到 GameState
   - 添加 `IsPlantSelectedOrPending()` 和 `IsSeedChooserFullIncludingPending()` 方法

2. **仓库禁用状态**：
   - 在 `SeedChooserRenderSystem` 添加 `drawDisabledOverlay()` 方法
   - 使用黑色半透明遮罩（alpha=120），与游戏中卡片禁用效果一致
   - 检查 selected 和 pending 两种状态

3. **按钮文字居中**：
   - 使用 `s.titleFont.Size` 计算文字高度
   - `textY = config.SeedChooserButtonY - textHeight/2` 实现垂直居中

4. **按钮文字颜色**：
   - 禁用时：`color.RGBA{0, 0, 0, 255}` (黑色)
   - 可点击时：`color.RGBA{255, 220, 100, 255}` (金黄色，与标题一致)

5. **手形光标**：
   - 在 `SeedChooserInputSystem` 添加悬停状态追踪（`isHoveringCard`, `isHoveringSlotCard`, `isHoveringButton`）
   - 添加 `ShouldShowHandCursor()` 方法
   - 在 `game_scene_utils.go` 的 `updateMouseCursor()` 中集成选卡界面光标检测
   - 在选卡阶段的 Update 中调用 `updateMouseCursor()`

6. **Glow 效果**：
   - **问题原因**：Glow 在按钮之前绘制，被按钮图片覆盖
   - **修复方案**：调整绘制顺序为 按钮 → Glow → 文字

- `pkg/systems/seed_chooser_input_system.go` - 添加 pending 状态和悬停追踪
- `pkg/systems/seed_chooser_render_system.go` - 修复禁用状态、按钮文字和 Glow 效果
- `pkg/scenes/game_scene.go` - 在选卡阶段调用 `updateMouseCursor()`
