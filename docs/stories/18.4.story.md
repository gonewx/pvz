# Story 18.4: 实体序列化扩展性重构

## Status

Done

## Story

**As a** 开发者,
**I want** 重构实体序列化系统使其具备扩展性,
**so that** 新增实体类型时无需修改多处代码，且现有僵尸类型（撑杆僵尸、旗帜僵尸）能正确保存和恢复。

## Acceptance Criteria

1. **Bug 修复：撑杆僵尸存档恢复**
   - 撑杆僵尸存档后恢复仍为撑杆僵尸（不再变成普通僵尸）
   - 撑杆僵尸的特有状态（HasPole, IsJumping）正确保存和恢复
   - 旗帜僵尸存档后恢复仍为旗帜僵尸

2. **使用 ZombieTagComponent 识别僵尸**
   - 移除 `isZombieBehavior()` 硬编码的行为类型列表
   - 使用 `ZombieTagComponent` 查询所有僵尸实体
   - 新增僵尸类型自动被识别（只需工厂函数添加 ZombieTagComponent）

3. **使用 UnitID 作为类型标识**
   - 移除 `behaviorTypeToZombieType()` 类型转换函数
   - 直接使用 `BehaviorComponent.UnitID` 作为 ZombieData.ZombieType
   - 恢复时根据 UnitID 选择正确的工厂函数

4. **工厂函数注册表**
   - 创建僵尸工厂函数注册表 `zombieFactories map[string]ZombieFactory`
   - 恢复时通过 UnitID 查找对应的工厂函数
   - 新增僵尸类型只需在注册表添加一行

5. **特有组件状态的通用处理**
   - 支持收集和恢复 `PoleVaultComponent` 状态
   - 架构设计支持未来其他特有组件（如气球僵尸的飞行状态）

6. **版本兼容性**
   - 更新 BattleSaveVersion 版本号
   - 旧版本存档提示用户需要重新开始

7. **单元测试**
   - 添加撑杆僵尸序列化/反序列化测试
   - 添加旗帜僵尸序列化/反序列化测试
   - 验证工厂注册表正确工作

## Dev Notes

### 问题背景

存档恢复后撑杆僵尸变成普通僵尸，原因分析：

1. **isZombieBehavior() 遗漏**：`pkg/game/battle_serializer.go:451-465` 没有包含 `BehaviorZombiePolevaulter` 和 `BehaviorZombieFlag`

2. **behaviorTypeToZombieType() 遗漏**：`pkg/game/battle_serializer.go:467-479` 没有撑杆/旗帜僵尸的类型映射，默认返回 "basic"

3. **restoreZombies() 遗漏**：`pkg/scenes/game_scene_init.go:949-958` switch 语句没有 "polevaulter" 和 "flag" 分支

### 现有基础设施

项目已有支持扩展的组件：

```go
// ZombieTagComponent - 统一标识僵尸实体
// 位置: pkg/components/zombie_tag.go
type ZombieTagComponent struct{}

// BehaviorComponent.UnitID - 已存储正确的单元ID
// 位置: pkg/components/behavior.go
type BehaviorComponent struct {
    Type            BehaviorType
    UnitID          string  // "zombie", "zombie_polevaulter", "zombie_flag" 等
    ZombieAnimState ZombieAnimState
}
```

### 工厂函数映射

```go
// 所有僵尸工厂函数位于: pkg/entities/zombie_factory.go
var zombieFactories = map[string]func(*ecs.EntityManager, ResourceLoader, int, float64) (ecs.EntityID, error){
    "zombie":             NewZombieEntity,
    "zombie_conehead":    NewConeheadZombieEntity,
    "zombie_buckethead":  NewBucketheadZombieEntity,
    "zombie_flag":        NewFlagZombieEntity,
    "zombie_polevaulter": NewPolevaulterZombieEntity,
}
```

### 架构原则

- **开放-封闭原则**：新增僵尸类型无需修改序列化核心逻辑
- **单一职责**：工厂函数负责创建，序列化器负责收集/恢复
- **ECS 模式**：使用组件（ZombieTagComponent）而非行为类型判断
